# My Tadiran icon

- `icon.png`: selected plugin icon, 100 × 100 pixels, for Homebridge.
- `icon-original.png`: larger original, 1254 × 1254 pixels.

The icon depicts a wall-mounted air conditioner with airflow on a blue background. It is an original illustration created with assistance from OpenAI's image generator and selected by the plugin maintainer. It does not use the Tadiran or Homebridge logos.
