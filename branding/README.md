# My Tadiran icon

- `icon.png`: selected plugin icon, 100 × 100 pixels, for Homebridge.
- `icon-original.png`: maintainer-provided original, 2613 × 2613 pixels.

The icon combines an air conditioner and a centered T, with white shapes and turquoise-to-blue airflow on a warm gray background. The initial concept was developed with assistance from OpenAI's image generator, converted to editable vectors, and refined by the plugin maintainer. The submitted PNG preserves the maintainer's final artwork. It does not use the Tadiran or Homebridge logos. These files are provided under this repository's MIT license.
